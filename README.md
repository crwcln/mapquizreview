Cairn — AP World History Map Study & Review Platform
Cairn is a high-performance, feature-rich web application engineered specifically for students to master historical map quizzes for AP World History. Designed with sleek aesthetics, fluid animations, and advanced study mechanics, Cairn turns historical geography review into an engaging, immersive experience.

🌟 Key Features
🗺️ Advanced Map Quiz Engine
Dynamic Historical Layers: Interactive mapping support for historical regions, rivers, seas, continents, oceans, trade routes, and empires with animated, color-coded highlights (e.g., water features glowing blue, distinct styling for land empires).

Multiple Game Modes:

Name this Highlighted Region: Identify empires or trade routes highlighted on the map.

Click the Region / Reverse Quiz: Get prompted with a historical location and click the corresponding area on the map.

Smart Weak-Spot Tracking: Automatically tracks user error frequency and miss-counts over time, powering a dedicated "Review Missed Regions" study tab and flashcard mode to target areas needing the most practice.

🤖 Built-In AI Assistants (Gemini API Integration)
Bottom-Right AI Bubble: A floating assistant powered by a user-configurable Gemini API key for instant study help.

Dedicated Full-Screen AI Page: Rebranded with a cool, theme-conforming name and accessible via a clean robot icon (🤖), offering an immersive, full-screen study chat interface.

🛠️ Comprehensive Admin Panel & Analytics
Organized Tabs: Cleanly separated pages and sub-tabs to eliminate endless scrolling.

Live Analytics Dashboard: Real-time tracking of active users, device breakdowns, quiz performance metrics, and recent system activity.

Streamlined Admin Controls: Interactive management with keyboard enhancements—such as password input fields that instantly submit on pressing Enter.

🎨 Customization, Themes & Cloaking
Universal Settings Page: Features multiple themes with distinct overall colorways, background types, and custom fonts, coupled with animated sliders.

about:blank Cloaking: Built-in stealth features with preset profiles and an emergency panic shortcut key for complete privacy.

Centered UI Elements: Cleanly centered 1-Year and 2-Year slider controls.

✨ Immersive Polish & Micro-Interactions
Ambient Space Audio: Atmospheric background music (enabled by default, with an easy toggle in settings).

Immersive Loading & Onboarding: An eye-catching introductory hook on startup, a first-time user tutorial, and a professional cookie consent banner.

Changelog Popups: Automatically surfaces update logs when the version changes, dismissing until the next update after clicking "Got it".

Refined UI Icons & Tooltips: Upgraded icons across top bars and navigation panels with descriptive hover tooltips, plus a question mark (❓) icon for feedback.

Responsive Desktop Optimizations: Custom-styled desktop dropdowns and calendars that gracefully fall back to native device inputs on mobile for optimal performance.

Dynamic Feedback Animations: Smooth confirmation effects for additions, deletions, clipboard copying, JSON data pasting, and a red shake-and-outline animation for incorrect passwords or map selections.
